Superposition

This page adds ten travelling sine waves. Each wave has its own wavelength, amplitude, phase, and velocity. The Reset button now loads a wave-packet preset: nearby wave numbers, center-weighted amplitudes, and aligned phases so that the resultant forms a localized packet. To understand how things work deactivate all components and use only two components and see how the resultant changes. Add individual components one by one to create a wave packet kind of thing.

Mathematical model

yᵢ(x,t) = Aᵢ sin[2π(x − m vᵢt)/λᵢ + φᵢ],    y_resultant(x,t) = Σ yᵢ(x,t)

Each component has its own velocity \(vᵢ\). Wavelength \(λᵢ\), amplitude \(Aᵢ\), phase \(φᵢ\), and velocity \(vᵢ\) can be adjusted separately for each of the ten waves. The global velocity multiplier \(m\) scales all component velocities together. Constructive and destructive interference are visible directly in the resultant curve.

Tip: press Reset to return to a packet-like preset. The component phases are aligned so the waves add strongly near one region and cancel away from it.
