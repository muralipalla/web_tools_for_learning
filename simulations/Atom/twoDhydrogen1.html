2D Hydrogen Orbitals: Probability Dots and Radial Nodes

This reworked version makes radial nodes clearly visible. The background heatmap shows \(|\psi|^2\), dense dots are sampled from the same probability distribution, and dashed yellow rings mark radial nodes where the radial wavefunction changes sign. The inset now plots the radial probability function P(r)=2πr|ψ(r)|² instead of just |ψ|². The canvas background is pure black, the heatmap uses a high-contrast false-color palette, and the probability dots are pure white.

Why the radial nodes are now visible

\(\psi(r,\theta)=R_{n,m}(r)\Phi_m(\theta)\),   \(P(r)=2\pi r|\psi(r)|^2\)

A radial node occurs where \(R_{n,m}(r)=0\). In a pure dot plot, a thin zero-probability ring can be hidden by neighboring dots. This version therefore uses three simultaneous cues: a dark heatmap gap, a dashed yellow node ring, and a smooth radial-probability inset where the zeros are marked.
